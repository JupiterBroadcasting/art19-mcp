## 2. Key API Discovery: Active Versions Are Locked

Editing a marker on an `active` (published) version fails:

```
422 not_eligible_for_changes | Episode version cannot modify marker points when status is active
```

- **MCP tools:** cannot edit live-episode markers. Must create a NEW version
  (`copy_active_version: true` reuses audio — no re-upload) on draft, edit,
  submit, republish. This is the "backfill" flow.
- **ART19 web UI:** CAN edit live-episode markers. Under the hood it does a
  version copy + republish (episode `active_version_id` changes; new
  `release_periods` entry appears). Confirmed on 674: version went
  `f236d9a4-...` → `e542f02b-f507-4f77-b065-a5a61fe0fbae` after a UI edit.

## 3. Decision: Pre-Roll Duration 120s → 90s

Cohost suggested shortening pre-roll to 90s (most skippable slot; midroll at
26:48 carries the revenue).

**Applied:**

- `build-marker-set` in `art19_mcp.bb`: pre-roll `:maximum_content_duration 120` → `90`. Post-roll stays 120s.
- Fallback default (`:maximum_content_duration (or ... 120)`) → 90.
- Tool schema description + `Default: 120` → 90.
- `docs/publishing-workflow.md`, `SPEC-prepare-episode-version-midrolls.md`: updated pre-roll to 90s.
- `docs/markers-and-ads.md`: added "Editing Markers on a Published Episode" section.
- `docs/publishing-workflow.md`: "Replace Audio" section rewritten as "Backfill" runbook (copy_active_version reuses audio; pre-roll 90s default; UI-vs-API note).

**Live episodes 675 + 674:** user edited pre-roll to 90s via the ART19 UI
(confirmed: both now show pre-roll `maximum_content_duration: 90.0`). No API
republish needed for already-live episodes.

**Backfill strategy (user's call):** since backfilling old episodes already
requires a new version (to add midrolls), set pre-roll to 90s *during that*
new-version flow. Don't separately republish live episodes — the UI handles
one-offs, the new-version flow handles batch backfills. The 90s default makes
this automatic on the deployed server; on the old 3007 server, pass
`maximum_content_duration: 90` explicitly on the pre-roll marker.
